    Before you start

    Two files, once.

    Credentials live in a local file that never ships with the site.

    1. Copy the example config Copy-Item storage.config.example.json storage.config.json
    2. Create an OAuth client Google: a “TVs and Limited Input devices” client. Microsoft: a public/native app with device-code flow. Paste the ids into the config.
    3. Restart the studio npm run studio Then connect above.
    Why a local server?

    Google and Microsoft require an OAuth client secret for this flow. Putting it in the portfolio's JavaScript would publish it. This server binds to 127.0.0.1, keeps secrets in memory, and writes only the refresh token to a gitignored file.

    • No analytics, no third-party scripts, no remote fonts.
    • Uploaded files are made publicly readable so the site can embed them.
    • Strip location and camera metadata before uploading anything personal.
    • Deleting here deletes the stored file; the site link will break.
    • Read docs/STORAGE.md for the full setup.
